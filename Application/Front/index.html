CryptoCampus — Création d’une Cryptomonnaie Universitaire

Projet BUT Informatique — Présenté par Sevo Hakobyan & Thomas Feler. Monnaie d'engagement pour récompenser l'entraide, tutorat et participation sur le campus.

Objectif : prototype fonctionnel démontrant token (ERC-20 testnet), API backend, interface de transfert et simulation d'économie.

Sommaire
Contexte • Architecture • Backlog • Sprints • Livrables

Contexte et objectifs

  • Récompenser l'implication (tutorat, bénévolat).
  • Permettre échanges P2P et accès premium.
  • Utiliser token pour gouvernance (votes).

Résumé technique rapide

Token ERC-20 (Sepolia testnet) — Backend (ASP.NET Core / Node.js) — DB (Postgres/Mongo) — Auth (JWT + 2FA) — Dashboard admin pour supervision.

Architecture fonctionnelle

  1. Frontend (Web) — UI pour transferts et historique
  2. API Backend — logique métier, sécurité
  3. Smart Contract — token ERC-20
  4. Base de données — users, logs
  5. Dashboard Admin — supervision & actions

Schéma de flux (texte)

Utilisateur → Frontend → Backend API → Smart Contract (Sepolia) → Blockchain. Backend enregistre logs et synchronise DB.

Technos recommandées

  • Backend : ASP.NET Core (C#) ou Node.js
  • Smart contract : Solidity (ERC-20) — Testnet Sepolia
  • DB : PostgreSQL / MongoDB
  • CI/CD : GitHub Actions

Notes techniques

Astuce

Pour intégrer la vraie blockchain : utiliser web3.js / ethers.js et appeler le smart contract ERC-20 déployé sur Sepolia. Le backend doit authentifier & signer les opérations sensibles côté serveur si besoin.
